# Northwind Consulting: Responsible AI Usage Policy

*Synthetic sample document for demonstrating the RAG pipeline. Northwind Consulting is fictional.*

## Approved tools

Employees may use only AI tools from the approved list maintained by the IT security team. The current approved tools are the company-managed Claude workspace and the Microsoft 365 Copilot licence. Personal accounts on public AI chatbots must not be used for any work-related task.

## Data classification

Client confidential data, personal data (names, emails, phone numbers, ID numbers) and unreleased financial information must never be pasted into an AI tool that is not on the approved list. Public and internal-only information may be used in approved tools.

## Human review

AI-generated output must be reviewed by a qualified person before it is sent to a client or used in a decision. The employee who sends the work remains fully accountable for its accuracy. AI-generated code must pass the normal code review and automated test process before deployment.

## Disclosure and incidents

Client deliverables that contain substantial AI-generated content must carry a disclosure note where the client contract requires it. Suspected leaks of confidential data into an AI tool must be reported to the security team within 24 hours through the incident portal.
